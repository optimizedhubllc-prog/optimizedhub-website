Google Integration Disclosure
How Optimized Hub Media LLC uses Google's Gmail API
"Optimized Hub Media Operations" is the internal set of tools Optimized Hub Media LLC uses to run its own business. It connects to a single Google account, the company owner's business Gmail (pedro@optimizedhub.com), through the Gmail API for two purposes: sending the company's own business email (such as payment confirmations, audit reports a prospect requested, and internal alerts) and logging the company's own software expenses from vendor receipts.
This is separate from our Database Reactivation and CRM services. Customers are never asked to connect a Google account. Gmail data is not sold, not shared with advertisers or data brokers, not used for advertising, and not used to train AI models, and only the owner can see it. Details are in our Privacy Policy.
